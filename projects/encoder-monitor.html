Encoder alerts were being generated correctly and going nowhere anyone would see them. This receives them as they fire, works out which node sent what, enriches them into something readable, and puts them on a wall. Alerts presented are accompanied by a configurable alert sound to get the attention of an operator even if he's not looking.

The problem

Live encoding runs across a set of encoder nodes managed centrally. When something goes wrong the encoders say so — but the alerts scatter, and there was no single surface where an operator could see the state of the whole estate at a glance.

The build

A Node service exposes a callback endpoint that the encoders post their alerts to directly, and renders them on a live dashboard.

  • Alert intake per node, with an allowlist controlling which sources are accepted
  • Severity resolved from the alert code, driving what the wall emphasises
  • Alerts that cannot be identified are dropped rather than displayed as noise
  • Event names enriched from the encoder management API so entries read as events, not identifiers
  • Node health polled over SNMP, since the management API does not expose the underlying statistics
  • Flat JSON persistence with atomic writes — active tiles clear on restart, history survives

What real hardware taught

Every incorrect assumption in this build was corrected by testing against production encoders rather than a specification.

The foundational one: the central manager configures alert callbacks, but it does not relay the alerts. Each node posts its own. That single fact reshapes the design — the allowlist has to name every node, and the payload carries no node field, so the sender itself is what identifies the source.

The one that cost the most time was a clock offset of roughly a minute and a half between the monitoring machine and the encoders, which quietly invalidated request authentication until it was detected and corrected for.

The outcome

Encoder health became something an operator can see and hear rather than something they discover. Outages on the encoder are minimized when alerts arrive in seconds, on a wall, with enough context to act on.
